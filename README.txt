========================================
  💌 给周紫艳的情书网页 · 部署说明
========================================

【文件】
index.html —— 就是整个网页（单文件，无需任何依赖）
双击即可直接打开预览。

【个性化（部署前先改！）】
用记事本打开 index.html，在最上面的 script 里找到：
  var HER_NAME = "周紫艳";   ← TA 的名字
  var MY_NAME  = "我";       ← 换成你自己的名字（落款用）
情话文字在同一段的 LETTER 数组里，一行一句，随意增删。

【部署方式 · 三选一】

1) Netlify Drop —— 最快，1分钟
   浏览器打开 https://app.netlify.com/drop
   把 index.html 拖进页面，立刻得到一个 https 链接。
   （免费注册账号后链接长期有效）

2) GitHub Pages —— 永久免费
   注册/登录 GitHub → 新建仓库（Repository）
   上传 index.html → 仓库 Settings → Pages
   → Source 选 main 分支 / 根目录 → 保存
   稍等一两分钟，得到  https://你的用户名.github.io/仓库名/

3) 传统虚拟主机 / 宝塔 / Nginx
   把 index.html 放进网站根目录即可，完事。
